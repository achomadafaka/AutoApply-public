# Roadmap

The current release candidate covers local job tracking, optional model-assisted drafts and a guarded Greenhouse review flow. Next areas worth validating:

1. A profile and résumé setup screen so users don't have to edit dotenv files.
2. Better handling of interrupted review sessions and manual receipt reconciliation without treating an attempt as a success.
3. Document preview with an explicit résumé choice per application.
4. Add other ATS adapters only when the supported flow can be verified with controlled fixtures and actual authorized review.

Bulk sending and automatic final submission are out of scope.
